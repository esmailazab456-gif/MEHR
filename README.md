# MEHR Platform Web

Foundation-only web project for the MEHR EdTech / Metaverse platform.

## Getting Started

```bash
npm install
npm run dev
```

The site will be available at `http://localhost:3000`.

## Folder Structure

- `components/` — Shared UI elements (layout, navigation, footer).
- `pages/` — Route-based pages for Next.js.
- `services/` — Placeholder for future API/service integrations.
- `utils/` — Shared utilities and helpers.
- `styles/` — Global styles and theme definitions.

## Notes

This phase establishes the technical foundation only (structure, linting,
formatting, and deployment readiness). Feature development will follow in
subsequent tasks.
